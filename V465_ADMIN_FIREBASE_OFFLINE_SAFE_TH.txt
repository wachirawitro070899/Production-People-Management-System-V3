V465 - Admin Firebase Offline Safe

แก้ปัญหา: Admin กดบันทึกแล้วขึ้นว่า Firebase ยังไม่เชื่อมต่อ

สิ่งที่แก้
1. เมื่อ Admin กดบันทึก ระบบจะเก็บข้อมูลลง Local Storage ก่อนทันที
2. ระบบรอ/พยายามเชื่อม Firebase อัตโนมัติสูงสุดประมาณ 12 วินาที
3. ถ้า Firebase ยังไม่พร้อม จะไม่แจ้งว่าข้อมูลหาย แต่แจ้งว่าเก็บไว้ในเครื่องและรอซิงก์
4. เมื่ออินเทอร์เน็ตกลับมา ระบบจะซิงก์ข้อมูลที่ค้างขึ้น Firebase อัตโนมัติ
5. มีการตรวจข้อมูลค้างทุก 30 วินาที
6. การซิงก์ยังใช้ Preserve/Merge เพื่อไม่ลบข้อมูลเก่าของ Admin และพนักงาน
7. getAppHealth() เพิ่ม pendingCloudSync เพื่อดูว่ามีข้อมูลรอซิงก์หรือไม่

หมายเหตุสำคัญ
- ขณะออฟไลน์ ข้อมูลจะอยู่ในเบราว์เซอร์/เครื่อง Admin เครื่องนั้นก่อน จนกว่าจะซิงก์สำเร็จ
- ห้ามล้าง Site Data/Local Storage ของเบราว์เซอร์ในช่วงที่ยังมีข้อมูลรอซิงก์
- เมื่อ Firebase กลับมา ระบบจะส่งข้อมูลที่ค้างขึ้นฐานข้อมูลกลางเอง
