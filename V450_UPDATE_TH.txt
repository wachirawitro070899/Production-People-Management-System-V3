V450 - Live Attendance + Employee Edit Fix

1. การเช็คชื่อจะรอให้ Firebase บันทึกสำเร็จก่อนแสดงข้อความ "เช็คชื่อสำเร็จ"
2. Attendance ที่เช็คจากเครื่องพนักงานจะถูกส่งไป ppms/attendance โดยตรง ทำให้หน้า Admin เห็นข้อมูลทุกเครื่องแบบ Live
3. การแจ้งเข้าสายล่วงหน้าและการลา ส่ง Attendance ขึ้น Firebase โดยตรงเช่นกัน
4. การแก้ไขชื่อ/ข้อมูลพนักงานจะเขียนข้อมูลพนักงานคนนั้นขึ้น Firebase โดยตรงและเพิ่ม updatedAt
5. หลัง Refresh ชื่อที่แก้ไขแล้วจะไม่ถูกข้อมูลเก่าจาก Firebase เขียนทับกลับ
6. หาก Firebase/อินเทอร์เน็ตมีปัญหา ระบบจะแจ้งว่าไม่สามารถส่งขึ้นเว็บ แทนการแจ้งสำเร็จแบบเดิม
