PPMS V428 - Admin Factory Pin Map

- ยกเลิกปุ่มใช้ตำแหน่ง GPS ปัจจุบันสำหรับการตั้งหมุดโรงงาน
- Admin ค้นหาสถานที่ แล้วคลิกบนแผนที่/ลากหมุดเพื่อเลือกตำแหน่งโรงงานเอง
- Latitude / Longitude ถูกล็อกให้อ่านจากหมุดบนแผนที่ ลดการกรอกพิกัดผิด
- แสดงวงรัศมีเช็คชื่อบนแผนที่ และอัปเดตตามค่ารัศมี สูงสุด 50 เมตร
- การค้นหาสถานที่ใช้ OpenStreetMap Nominatim เป็นเพียงจุดเริ่มต้น; Admin ต้องปรับหมุดให้ตรงอาคารก่อนบันทึก
- GPS Accuracy ยังคงใช้เฉพาะตอนพนักงานเช็คชื่อจริง
- ระบบ Examination, Training, Skill Matrix, Evaluation Plan และ Attendance KPI เดิมยังคงอยู่
